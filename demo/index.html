DynamicBox

A field that shows its examples by editing them. The part of the previous example that still applies stays where it is, and only the rest changes -- so the line looks like it is being reconsidered rather than replaced.

Nothing is typed into the field's value. This is its placeholder, so a reader who starts typing is not fighting the animation -- and touching the field stops it for good.

The order it chose

Nearest neighbour by shared prefix, from every possible start, then reversal moves while they save characters. Costing the loop rather than the line is what stops a short example being promoted to first place for no reason.

    What it stores

    The same examples as one packed string. Each record is the number of characters to delete and then the text to append, so a stem shared by eight examples is stored once.

    
  
    

  
    Your own examples
    
  
    One per line. Try a group that shares a phrase and one that shares
  nothing at all: the first should settle into a visible rhythm.
    
  
  
    

  
    How the pause is placed
    
  
    Deleting is not uniform. It starts slow and quickens, which reads as someone changing their mind
  about a word rather than as a buffer being cleared, and the beat afterwards comes before the new text,
  so the half-finished line is what sits on screen. That beat is why the shared stem is readable instead
  of being a flicker between two questions.
